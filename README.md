# 🔐 CipherVault

Secure. Encrypt. Protect.

CipherVault is a Flask-based cybersecurity web application that allows users to securely encrypt and decrypt text using modern cryptographic algorithms.

---

## 🚀 Features

- ✅ AES-CBC Text Encryption
- ✅ AES-CBC Text Decryption
- ✅ Secret Key Validation
- ✅ Copy Encrypted Text
- ✅ Clear Input Fields
- 🚧 DES Encryption (Coming Soon)
- 🚧 RSA Encryption (Coming Soon)
- 🚧 File Encryption (Coming Soon)

## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/Aditya2917/CipherVault.git
```

2. Open the project

```bash
cd CipherVault
```

3. Install dependencies

```bash
pip install -r requirements.txt
```

4. Run the application

```bash
python app.py
```
